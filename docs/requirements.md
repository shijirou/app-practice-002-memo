## 1. 目的
事務スタッフが、日常業務で発生する情報を手軽に記録・管理できるようにする。
メモの書き忘れや確認漏れを減らす。

## 2. 決定事項（未確認だった点）
クライアントに確認できないため、次の案で進める。変更があれば、このファイルを直す。

| # | 論点 | 決定 | 理由 |
|---|---|---|---|
| 1 | メモの項目 | 本文だけ（タイトルなし） | 書く手間を減らす。一覧には本文の最初の数行を出す |
| 2 | 並び順 | 作成日時の新しい順 | 「新しい順の一覧」の要望 |
| 3 | 検索 | キーワードを含む本文を絞り込む（部分一致・大文字小文字を区別しない） | 件数が増えても探せる |
| 4 | 削除 | 確認メッセージのあと、完全に消す。元に戻せない | 機能を増やさない |
| 5 | 保存先 | サーバー側の DB（PostgreSQL） | ブラウザのデータを消してもメモが残る |
| 6 | 利用者 | 1 人専用。ログインなし | 要望どおり |
| 7 | 保存の操作 | 3 操作以内（入力欄をクリック → 入力 → 保存）。開いた直後は入力欄にカーソルがあり、2 操作でも保存できる | 「すぐ記録したい」 |
| 8 | 重要 | メモに「重要」の印を付け外しできる（印は 1 種類だけ）。並び順は変えず、「重要のみ」で絞り込む。検索と組み合わせられる | 大事なメモをすぐ見たい。タグ・カテゴリは作らない |
| 9 | 長いメモの表示 | 一覧では 3 行まで。カードを押すと全文が開く | 読むだけのときに、編集状態にしない |
| 10 | 編集の確定・取り消し | 編集中は「保存」ボタンだけ（編集ボタンの位置）。取り消しは Esc キー | 押し間違いを減らし、画面をシンプルにする |
| 11 | 画面の確認用モック | [mock/index.html](mock/index.html)（DB・API なし）で、見た目と操作を確認済み | 作る前にデザインを確認する |

## 3. 機能要件
| ID | 機能 | 内容 | 元の希望 |
|---|---|---|---|
| F1 | 登録 | 本文を入力し、「保存」ボタン（または Ctrl+Enter）で保存する。空のメモは保存できない。保存後、入力欄は空になる。入力欄は文字が増えると伸びる | 1 |
| F2 | 一覧 | 保存したメモを、作成日時の新しい順に並べて表示する。日時（曜日つき）と本文を出し、「全 n 件（重要：m 件）」を表示する。件数が増えたら一覧だけがスクロールする。長い本文は 3 行まで、カードを押すと全文が開く | 2 |
| F3 | 検索 | 検索欄にキーワードを入れると、本文に含むメモだけに絞り込む（一致した文字を目立たせる）。空に戻すと全件 | （探しやすさ） |
| F4 | 編集 | 一覧のメモの「編集」を押すと、その場で本文を直せる。「保存」（または Ctrl+Enter）で確定、Esc で取り消し（書きかけがあるときは、破棄してよいか確認する） | 3 |
| F5 | 削除 | 一覧のメモの「削除」を押し、確認メッセージで OK すると消える | 4 |
| F6 | 重要 | 一覧のメモの「重要にする／重要を外す」で、印を付け外しする。重要なメモは左端に金色の線が出る。「重要のみ」ボタンで、重要なメモだけを表示する（検索と組み合わせ可） | （大事なメモを見つけやすく） |

## 4. 非機能要件
| 項目 | 内容 | 元の希望 |
|---|---|---|
| 対応機器 | パソコンのブラウザ（画面幅 1024px 以上を想定）。スマートフォン・タブレット向けの最適化はしない | 5 |
| 操作のしやすさ | 画面は 1 つ。説明なしで使える。文字は読みやすい大きさ | 6 |
| 速さ | 保存・検索の結果が、1 秒以内に画面に出る | |
| 文字数 | 本文は 1〜1000 文字 | |
| 安全性 | **本物の顧客情報・個人情報は入れない**（テストやサンプルも架空の内容）。ログインがないため、使うパソコン自身の中だけで動かす（外部には公開しない） | |
| 秘密情報 | DB のパスワードなどは `.env` に書き、GitHub に載せない | |

## 5. 画面
1 画面のみ。左に入力欄（保存ボタンは見出しの右端）、右に検索欄・「重要のみ」ボタン・一覧を置く。
図と部品の詳細は [画面デザイン](screen-design.md)。

## 6. データ
保存するのは「メモ」1 種類（ID・本文・重要・作成日時・更新日時）。
ER 図と API は [データ設計](data-design.md)。

|---|---|---|

バージョンの一覧は [技術スタック](tech-stack.md)。

## 8. 対象外（今回は作らない）
- ログイン・複数ユーザー
- タイトル、タグ、カテゴリ、添付ファイル
- 削除したメモの復元（ごみ箱）
- 複数台のパソコンでの共有・外部への公開
- スマートフォン・タブレット向けの最適化
- Excel / CSV への出力

## 9. 完成の目安
- F1〜F6 が動く。
- ブラウザを閉じて開き直しても、メモが残る。
- 本文を入力して保存するまで、3 操作以内でできる。
- 実在の顧客情報・個人情報がどこにも入っていない。
