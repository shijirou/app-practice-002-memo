# 最終確認（2026-11-17）

機能 F1〜F6 と CI がそろった時点で、**公開リポジトリとしての安全面**と、**画面全体（モックとの見比べ・キーボード操作）**を確認した記録。
コードの品質チェックは [品質チェックの記録](quality-review.md) を参照。

## 1. 安全面（公開リポジトリ）

### 問題なし
| 確認したこと | 方法 | 結果 |
|---|---|---|
| 秘密情報が履歴に入っていないか | 全履歴を、鍵・トークンの形（`ghp_`・`sk-`・`AKIA`・秘密鍵など）で検索 | 該当なし |
| `.env` が GitHub に載っていないか | 履歴と追跡中のファイルを確認 | 一度も入っていない（`.env.example` の見本だけ） |
| パスワードの実値 | 履歴の `password=` などを検索 | 見本の文言と `${DB_PASSWORD}` だけ |
| 個人情報 | メールアドレス・電話番号・個人のパス・ユーザー名を検索 | 該当なし |
| 実在の人名・会社名 | 固有名詞を一覧にして確認 | すべて「架空」付き |
| コミットの作者のメール | `git log` | GitHub の非公開用アドレス（noreply）だけ |
| 画像・バイナリ | 追跡中のファイルの種類 | `gradle-wrapper.jar` だけ（下を参照） |
| `gradle-wrapper.jar` | Gradle 公式のチェックサムと比較 | 完全に一致（改ざんなし） |
| 部品の脆弱性 | 画面は `npm audit`、API は 79 部品を OSV（公開の脆弱性データベース）で照会 | どちらも 0 件 |
| API・DB の待ち受け | `netstat` | `127.0.0.1` だけ（品質チェック 3 回目で直した） |
| GitHub: 秘密情報の検出 | リポジトリ設定 | secret scanning・push protection とも有効 |
| GitHub: ルールセット | 設定 | 削除禁止・強制プッシュ禁止・PR 必須・CI（`check`）必須。例外なし |
| GitHub: Actions の権限 | 設定 | 既定は読み取りだけ。Actions による PR の承認は不可。CI の `permissions` も読み取りだけ。`pull_request_target` は使っていない |
| GitHub: そのほか | 設定 | シークレット・Webhook・デプロイキーはゼロ。コラボレーターは本人だけ |

### 直したこと
| # | 内容 | どうしたか |
|---|---|---|
| F-1 | Gradle 本体（ZIP）をダウンロードするとき、公式のものか検証していなかった（`distributionSha256Sum` が無い） | `gradle-wrapper.properties` に公式の SHA-256 を追加。新しい環境で取得する CI で検証される |

### 直したこと（GitHub の設定。ユーザーの確認のうえ、2026-11-17 に実施）

|---|---|---|

## 2. 画面（モックとの見比べ・操作）
| 確認したこと | 結果 |
|---|---|
| モック（`docs/mock/index.html`）と本物を、同じ幅で並べて比較（幅 1280・1024） | 配置・色・ボタンの位置・件数の表示が一致。違いは、モックだけにある注意書きのバナーのみ |
| 幅 1024px | 横のはみ出しなし。一覧だけがスクロールする（要件どおり） |
| 長いメモ | 3 行で切れて「続きを読む」が出る |
| キーボードだけの操作 | 開いた直後に入力欄。Tab の順は「検索 → 重要のみ → 重要にする → 編集 → 削除 → 続きを読む」。Enter で編集、Ctrl+Enter で保存、保存後は「編集」ボタンにカーソルが戻る。Enter で削除の確認が出る。最後まで通しでできた |
| ブラウザのコンソール・API の起動ログ | エラーも警告もなし |

品質チェック 1 回目の確認メモ I-8（幅 1024px 未満・Edge 以外のブラウザ・キーボードだけの通し操作）のうち、**1024px とキーボード操作は確認できた**。幅 1024px 未満は、要件で対象外（1024px 以上を想定）。Edge 以外のブラウザは、まだ確認していない。
