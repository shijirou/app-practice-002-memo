# 画面デザイン

[要件定義書](requirements.md) の「画面」の詳細。まだ作っていない画面の**設計案**。
ブラウザで見られるモックは [mock/index.html](mock/index.html)（ファイルをブラウザで開く。DB・API なしの見た目確認用）。
画面は 1 つだけ。パソコン（幅 1024px 以上）を想定。

## 完成デザイン（文字と線の図）

```
 背景: 濃いめのグレー
┌───────────────────────┐  ┌──────────────────────────────────┐
│ 新しいメモ       [保存] │  │ 検索                               │
│ ┌───────────────────┐ │  │ ┌──────────────────┐ [重要のみ]    │
│ │ ここに入力          │ │  │ │ キーワード          │              │
│ │ （開いた直後に      │ │  │ └──────────────────┘              │
│ │  カーソルあり）     │ │  │ 全 8 件（重要：2 件）                │
│ └───────────────────┘ │  │ ┌────────────────────────────┐ ▲ │
│ 0 / 1000 文字          │  │ │▌2026-11-16(月) 10:30         │ █ │
│      Ctrl+Enter でも保存 │  │ │▌          重要を外す 編集  削除 │ █ │
└───────────────────────┘  │ │▌架空商事の架空さんから電話。…  │ █ │
                           │ └────────────────────────────┘ ░ │
                           │ ┌────────────────────────────┐ ░ │
                           │ │ 2026-11-15(日) 16:05         │ ░ │
                           │ │        重要にする 編集  削除    │ ░ │
                           │ │ 会議室の予約は金曜 14 時…       │ ░ │
                           │ │ 続きを読む                     │ ▼ │
                           │ └────────────────────────────┘   │
                           └──────────────────────────────────┘
```
- 左端の太い線（▌）は「重要」のメモの印。右端の縦の帯は一覧のスクロールバー（いつも表示）。

### 編集中の 1 件（「編集」を押したあと）
```
┌────────────────────────────────┐
│ 2026-11-16(月) 10:30     [保存]   │  ← 「編集」ボタンがあった位置に「保存」
│ ┌────────────────────────────┐ │
│ │ 本文（直せる）                │ │
│ └────────────────────────────┘ │
│ Esc キーで取り消し                │
└────────────────────────────────┘
```

## 部品と役割
| 部品 | 要件 | 見た目・動き |
|---|---|---|
| 新しいメモの入力欄 | F1 | 複数行。開いた直後にカーソルがある。最初は 3 行分の高さで、文字が増えると伸びる。画面の高さに近づいたら欄の中でスクロール。1000 文字まで |
| 保存ボタン | F1 | 「新しいメモ」の見出しの右端。本文が空のときは薄くて押せない。押すと保存し、入力欄を空にして、一覧の先頭に出る |
| 文字数・案内 | F1 | 入力欄の下に「0 / 1000 文字」と「Ctrl+Enter でも保存」 |
| 検索欄 | F3 | 入力するたびに絞り込む。一致した文字は黄色で目立たせる |
| 重要のみボタン | F6 | 検索欄の右。縁は金色。押すと重要なメモだけを表示（薄い黄色に変わる）。検索と組み合わせられる |
| 件数 | F2・F3・F6 | 「全 8 件（重要：2 件）」。絞り込み中は「／ 表示 n 件」を付ける |
| メモのカード | F2 | 日時（曜日つき）と本文。重要は左端が金色の太い線。本文は 3 行まで表示 |
| 全文の開閉 | F2 | 3 行を超えるメモには「続きを読む」。カードのボタン以外のどこを押しても全文が開き、「閉じる」で戻る。編集中・文字の選択中は開閉しない |
| 重要ボタン | F6 | 日時の行の右側。「重要にする」「重要を外す」。小さく薄い文字 |
| 編集ボタン | F4 | そのカードが入力欄に変わる。「保存」だけを出し、「編集」と同じ位置・同じ大きさにする（連打で「削除」に当たらない）。取り消しは Esc |
| 削除ボタン | F5 | 日時の行の右端。確認メッセージで OK したときだけ消える。ほかのボタンより少し離す |
| 空の表示 | F2・F3 | メモがないとき「メモはまだありません」、絞り込みで 0 件のとき「見つかりませんでした」 |

## 3 操作で保存する流れ
1. 入力欄をクリックする（開いた直後はカーソルがあるので省略できる）
2. 文字を入力する
3. 「保存」を押す（または Ctrl+Enter）

## 配置の考え方
- 書くことが主役なので、入力欄は左で、いつも見える位置に置く。保存ボタンは見出しの右端に置き、1〜2 行のメモでも入力欄から近い。
- 「新しいメモ」と「検索」は、同じ高さの見出しで、枠の上端をそろえる。ページ上部の大きな見出しは置かない。
- 一覧は右。件数が増えたときは、一覧だけがスクロールする。
- 編集・削除・重要のボタンは、本文を読む視線の邪魔にならないよう、小さく薄くして日時の行に置く。
- 画面の幅は最大 1200px。それより広い画面では、中央に寄せる。
