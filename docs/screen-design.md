# 画面デザイン

[要件定義書](requirements.md) の「画面」の詳細。まだ作っていない画面の**設計案**（点と線の図）。
画面は 1 つだけ。パソコン（幅 1024px 以上）を想定。

### 編集中の 1 件（「編集」を押したあと）
```
┌────────────────────────────────┐
│ 2026-11-16 10:30                 │
│ ┌────────────────────────────┐ │
│ │ 本文（直せる）                │ │
│ └────────────────────────────┘ │
│            [キャンセル] [保存]     │
└────────────────────────────────┘
```

## 部品と役割
| 部品 | 要件 | 見た目・動き |
|---|---|---|
| 新しいメモの入力欄 | F1 | 複数行。開いた直後にカーソルがある。1000 文字まで。文字数を「0 / 1000 文字」で表示 |
| 保存ボタン | F1 | 本文が空のときは押せない（薄く表示）。押すと保存し、入力欄を空にして、一覧の先頭に出る |
| 検索欄 | F3 | 入力するたびに絞り込む。空にすると全件。件数を表示する |
| メモのカード | F2 | 日時と本文を表示。長い本文は最初の数行だけ（全文は編集で見られる） |
| 編集ボタン | F4 | そのカードが入力欄に変わる。「保存」で確定、「キャンセル」で元に戻す |
| 削除ボタン | F5 | 赤い文字。確認メッセージで OK したときだけ消える |
| 空の表示 | F2・F3 | メモがないとき「メモはまだありません」、検索で 0 件のとき「見つかりませんでした」 |

## 3 操作で保存する流れ
1. 入力欄をクリックする（開いた直後はカーソルがあるので省略できる）
2. 文字を入力する
3. 「保存」を押す（または Ctrl+Enter）

## 配置の考え方
- 書くことが主役なので、入力欄は左で大きく、いつも見える位置に置く。
- 一覧と検索は右に置く。検索欄は一覧のすぐ上。
- 画面の幅は最大 1200px。それより広い画面では、中央に寄せる。
